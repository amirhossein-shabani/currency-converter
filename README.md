# Currency Converter

A production-ready currency converter built with React and Vite.

## Features

- Real-time exchange rate lookup
- Persian RTL interface
- Theme switcher for light and dark mode
- Fast client-side conversion with React Query
- Responsive layout for desktop and mobile

## Scripts

- npm install
- npm run dev
- npm run build
- npm run lint

## Production notes

- Uses Vite for optimized production builds
- Includes a clean, responsive UI for Persian users
- Keeps stale-rate handling and error states visible to the user
